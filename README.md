# ReMarket - Vercel Ready

This is a static frontend version of the ReMarket project.

## Structure
- index.html
- products.html
- product-details.html
- sell.html
- dashboard.html
- about.html
- login.html
- register.html
- css/style.css
- js/script.js
- vercel.json

## Deploy
Upload this folder/repository to GitHub and import the repository into Vercel.
Framework preset: Other
Build command: leave empty
Output directory: leave empty

The site uses browser localStorage for registration, login and user-created listings, so no PHP/MySQL/server setup is required.
